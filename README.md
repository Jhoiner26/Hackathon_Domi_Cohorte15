# 🛵 DOMI Operator

Sistema de consola en **Java** para gestionar domicilios, clientes, repartidores (Bici, Moto, Carro, Dron) y cotización de pedidos con modo lluvia y calificaciones.

## Estructura del proyecto

* `com.domi.app` — Menú principal por consola (`Main.java`).
* `com.domi.modelo` — Clases de negocio (`Cliente`, `Pedido`, `Repartidor`, `Bici`, `Moto`, `Carro`, `Dron`, `Calificable`).
* `com.domi.servicio` — Lógica de validación, cotización y reglas operativas (`DomiService.java`).
